# 实验验收定义

## 数据与场景

平面房间、L形走廊、带矩形障碍物房间；种子42/43/44。前后外参为x=±0.30m、后雷达yaw=π，轮廓0.8×0.7m，均为合成模型。噪声模式为测距高斯标准差1cm，里程计速度比例偏差0.5%。

模型用10Hz瞬时平面射线采样，不伪装为真实MID360逐点时序，不生成无用途的虚假IMU。真实双雷达和IMU录包验证属于后续阶段。

## 阈值

- 建图：位置RMSE≤0.15m，已观测占据点到墙段距离P95≤0.15m，保存地图可读取，位姿图序列化成功，零碰撞。
- 定位：注入x=0.3m、yaw=10°初始误差，以实际模拟运动开始计时，15s内收敛至0.15m、5°。
- 正常导航：每场景3目标×3种子=27任务，Action成功且真值终点误差≤0.2m、10°，零碰撞。
- 取消：接受取消，模拟运动在0.5s内停止。
- 传感器中断：持续注入请求速度，command_guard仍须因扫描陈旧停车。
- 暂停/恢复：时间暂停时位置不动，恢复后不重放旧指令。
- 堵塞：Nav2有界失败，不能把评分器超时取消当作成功。
- 回放重启：重启完整进程，重新建立TF/SLAM状态；不接受旧TF作最新数据。

任何软件成功退出而缺少指标的情况都不算通过；失败报告保留。真实精度未知，不从合成成绩推断。
